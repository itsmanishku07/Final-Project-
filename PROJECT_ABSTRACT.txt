--------------------------------------------------------------------------------
                              ABSTRACT
--------------------------------------------------------------------------------

The AI-Powered Resume Screening and Job Matching System is a comprehensive 
web-based application designed to revolutionize the traditional recruitment 
process by leveraging artificial intelligence and machine learning technologies. 
This system addresses the challenges faced by both job seekers and recruiters 
in the modern job market by automating resume analysis, providing ATS 
(Applicant Tracking System) compatibility scores, and intelligently matching 
candidates with suitable job opportunities.

The primary objective of this project is to streamline the hiring process by 
reducing manual effort in resume screening while improving the accuracy of 
candidate-job matching. The system extracts key information from resumes 
including skills, experience, and education using AI-powered text analysis, 
then compares these attributes against job requirements to generate match scores.

For job seekers, the platform offers valuable insights into their resume's 
effectiveness through detailed ATS scoring, spelling error detection, missing 
section identification, and keyword suggestions to improve visibility to 
recruiters. For recruiters, the system provides automated candidate ranking, 
application management, and comprehensive dashboards to track hiring progress.

--------------------------------------------------------------------------------
                        SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------

The system follows a modern three-tier architecture:

1. PRESENTATION LAYER (Frontend)
   - Single Page Application (SPA) built with React
   - Component-based architecture
   - Context API for state management
   - Protected routes with role-based access

2. APPLICATION LAYER (Backend)
   - RESTful API design
   - Clean layered architecture:
     * Routes (API endpoints)
     * Services (Business logic)
     * Repositories (Data access)
     * Models (Data structures)
   - JWT token-based authentication
   - File processing services

3. DATA LAYER (Database)
   - Firebase Firestore collections:
     * users - User profiles and authentication data
     * resumes - Resume metadata and AI analysis results
     * jobs - Job postings and requirements
     * applications - Job applications and status
     * matches - Resume-job matching scores

--------------------------------------------------------------------------------
                      ATS SCORING ALGORITHM
--------------------------------------------------------------------------------

The ATS (Applicant Tracking System) scoring algorithm evaluates resumes 
across six key categories:

1. CONTACT INFORMATION (10 points max)
   - Email address: 3 points
   - Phone number: 3 points
   - LinkedIn profile: 2 points
   - Portfolio/GitHub: 2 points

2. SECTION STRUCTURE (20 points max)
   - Summary/Objective: 4 points
   - Work Experience: 5 points
   - Education: 4 points
   - Skills: 4 points
   - Projects: 3 points

3. KEYWORDS & SKILLS (25 points max)
   - High-value technical keywords: 2 points each
   - Medium-value keywords: 1 point each
   - Covers 50+ industry-standard skills

4. EXPERIENCE DETAILS (20 points max)
   - Employment dates: 5 points
   - Job titles: 5 points
   - Company names: 5 points
   - Action verbs: 5 points

5. QUANTIFIABLE ACHIEVEMENTS (15 points max)
   - Percentage metrics: 5 points
   - Dollar amounts/numbers: 5 points
   - Time-based improvements: 5 points

6. FORMATTING & READABILITY (10 points max)
   - Optimal length (400-1500 words): 4 points
   - Bullet points usage: 3 points
   - Proper formatting: 3 points

GRADING SCALE:
- A (85-100): Excellent - Highly ATS optimized
- B (70-84): Good - Well optimized for ATS
- C (55-69): Average - May pass basic ATS
- D (40-54): Below Average - Likely filtered out
- F (0-39): Poor - Will likely fail ATS screening

--------------------------------------------------------------------------------
                      INSTALLATION & SETUP
--------------------------------------------------------------------------------

PREREQUISITES:
- Node.js 18.x or higher
- Python 3.9 or higher
- Firebase account with Firestore enabled
- Git

BACKEND SETUP:
1. Navigate to backend-flask directory
2. Create virtual environment: python -m venv venv
3. Activate virtual environment: venv\Scripts\activate (Windows)
4. Install dependencies: pip install -r requirements.txt
5. Configure Firebase credentials in firebase-service-account.json
6. Set environment variables in .env file
7. Run server: python run.py

FRONTEND SETUP:
1. Navigate to frontend directory
2. Install dependencies: npm install
3. Configure Firebase in .env file
4. Run development server: npm run dev
